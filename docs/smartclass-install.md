# SmartClass installation

SmartClass has its own /smartclass.webmanifest, stable identity /smartclass and branded PNG icons. Ari retains its own /ari identity and manifest. Install from the browser menu on the welcome page or Kids dashboard. The standalone app starts at / and follows existing onboarding. No orientation is locked, so the alphabet game can still rotate.

This is an installed web app, not a separately signed APK or an app-store listing. It requires internet; no service worker caches child data, payment responses or large audio/video files. Existing browser storage and authentication remain unchanged. Clearing browser data may remove locally saved progress.
